# Design handoff — cutify the `sparkle-that-page` demo

**Goal:** Take the working demo at `https://wan-huiyan.github.io/cutify-this/` and
make it *genuinely* cute and stylish — a page that makes people smile and screenshots
it — without breaking any of the seven live effects.

This folder is the handoff package:

| File | What it is |
|---|---|
| `demo-standalone.html` | **The artifact you upload.** Self-contained (all 7 effects + CSS inlined, no external fetches), runs every effect live on load. Generated by `build_standalone.py` — re-run that after editing any effect. |
| `cutify-design-brief.md` | This file — the intent, constraints, and a ready-to-paste prompt. |

## How to hand off (to Claude Design)

1. Open a chat at **claude.ai** (the Design surface / Artifacts).
2. **Upload `demo-standalone.html`** (drag it in) so Claude can see it render and run.
3. **Paste the prompt** from the bottom of this file.
4. When Claude Design hands back (the "Send to Claude Code" button gives an
   `api.anthropic.com/v1/design/h/<id>` URL), bring that URL back here — the
   `claude-design-handoff-bundle` skill fetches + implements it into `demo.html`.

> Same prompt works for **taste-skill** agents or any designer — it's tool-agnostic.

## HARD constraints — must survive the redesign (do NOT break these)

The redesign is **visual only**. The behavior contract is load-bearing:

1. **All 7 effects keep working**, wired exactly as now: fairy-wand cursor, sparkle
   trail, scroll-depth indicator, tab-title peekaboo, click confetti, ambient
   floaters, cute-chrome touches. Don't remove or rewire them.
2. **The control panel stays functional** — the per-effect checkboxes, the variant
   `<select>`s, and the `🎨 Palette` selector must keep toggling/​switching effects.
   (Restyle it beautifully; keep the wiring.)
3. **Keep the `data-*` contract**: effects read `data-wand / data-trail / data-scroll /
   data-confetti / data-floaters / data-palette` off `<html>`. Keep the
   `SparkleThatPage.<name>.destroy()` teardown.
4. **Accessibility & perf are non-negotiable**: every motion effect already respects
   `prefers-reduced-motion: reduce`; overlays are `pointer-events:none` (never block
   clicks/scroll); pointer effects no-op on touch. The redesign must preserve all of this.
5. **Stay zero-dependency, single-file** — no frameworks, no build, no CDN JS. CDN
   *fonts* (Google Fonts `<link>`) are the one allowed exception.
6. Keep the identity: title **sparkle-that-page**, the **cutify-this** bundle, and the
   install line `/plugin install sparkle-that-page@wan-huiyan-cutify-this`.

## What to push on — the actual design ask

The current page is functional-but-plain (a centered column, a floating checkbox panel).
Make it *designed*:

- **A real hero.** Right now the title is just big text. Give it presence — a
  composed hero that demonstrates the magic immediately (the effects are the product;
  let the hero *be* a playground).
- **Typography with a point of view.** Pick a characterful display face for the
  wordmark + a clean body face (Google Fonts OK). Establish a real type scale, not
  three sizes of system-ui.
- **Depth & spacing system.** Layering, soft shadows, intentional rhythm — not flat
  cards floating in a gradient. Make the whitespace deliberate.
- **The control panel as a delightful object.** It's the main interaction — make it
  feel like a toy/console, not a settings form. (Keep it usable + accessible.)
- **Motion with restraint.** Tasteful entrance/hover motion on the chrome that
  *complements* the effects rather than competing with them. Honor reduced-motion.
- **Charming, specific micro-copy.** Replace generic section text with copy that has
  personality (the current copy is a starting point, improve it).
- **Responsive + both color schemes.** Looks great at mobile width; the page chrome
  reads in light and dark.

## Aesthetic direction

**Recommended — "elevated kawaii / candy-arcade."** Keep the candy palette
(pinks/purples/gold) but give it craft: refined pastel gradients with real depth,
a playful-but-legible display font, sticker/badge motifs, soft glow. Think "the
cutest dev tool you've ever seen," not "a children's site." This matches the
`cutify-this` brand and the house style of the sibling repos.

Two alternatives worth exploring (Claude Design can show options):

- **Cottagecore-meadow** — the `meadow` palette (rose/teal/lavender/peach), soft,
  warm, hand-made, botanical. Pairs with the leaves/sakura floaters.
- **Neon mission-control** — the `neon` palette (cyan/lime/magenta on near-black),
  glow everywhere, arcade energy. Pairs with the fairydust/glow effects.
