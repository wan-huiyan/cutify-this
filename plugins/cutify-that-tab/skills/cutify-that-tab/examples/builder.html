Check and export

    The check is a JavaScript port of the xml, crisp, margin and contrast checks in check-favicon.py, run on the exact SVG you copy. Contrast is CIEDE2000 dE ≥ 22.5 against one colour per icon: the tile fill if there is a tile, otherwise the colour covering the most cells. Eyes, outlines and accents are not measured, and the threshold is calibrated on five field results, so treat it as a smoke alarm. The --html link check is not ported.
